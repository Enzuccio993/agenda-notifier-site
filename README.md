# Agenda Notifier public site

Sito statico destinato esclusivamente al branding OAuth pubblico di Agenda
Notifier. Non contiene installer, credenziali, analytics, cookie o script remoti.

## Pubblicazione

Pubblicare il contenuto di questa cartella nella radice del repository pubblico
`Enzuccio993/agenda-notifier-site` e abilitare GitHub Pages dal branch `main`,
cartella `/ (root)`.

URL attesi:

- `https://enzuccio993.github.io/agenda-notifier-site/`
- `https://enzuccio993.github.io/agenda-notifier-site/privacy/`
- `https://enzuccio993.github.io/agenda-notifier-site/terms/`
